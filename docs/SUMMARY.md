# DixTune — обзор проекта

DixTune — автоматический загрузчик аудио с YouTube-каналов. Скачивает аудио, вырезает рекламные вставки через SponsorBlock и предоставляет веб-интерфейс для управления каналами.

## Назначение

- Автоматизация загрузки аудио с YouTube-каналов: музыка, подкасты, лекции.
- Удаление рекламных вставок через SponsorBlock.
- Управление каналами и просмотр логов через веб-интерфейс.
- REST API + Swagger для управления и интеграции.

## Ключевые возможности

- Автоматическая синхронизация со случайным интервалом через APScheduler.
- Ограничение по дате, чтобы не скачивать старые выпуски.
- Опциональная транслитерация имён папок.
- Ротация логов и просмотр логов через веб-интерфейс.
- Остановка синхронизации без потери текущего файла.
- Basic Auth для защиты от несанкционированного доступа.
- Опциональный обход ограничений YouTube: ByeDPI, Deno для n challenge, cookies, PO Token Provider (bgutil).
- Постобработка аудио: очистка имён и тегов, теги `date` и `artist` для MP3.
