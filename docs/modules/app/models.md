# models.py

**Версия файла:** `261012.03`

## Назначение

Модуль содержит ORM-модели SQLAlchemy для хранения данных о каналах YouTube и журнале синхронизации. Определяет таблицы `channels` и `sync_logs`, их колонки, ограничения и значения по умолчанию. Явных функций и методов в модуле нет.

## Основные классы

### `Channel`

Модель канала YouTube. Таблица: `channels`.

| Поле | Тип / параметры | Назначение |
|---|---|---|
| `id` | `Integer`, primary key, index | Первичный ключ |
| `url` | `String`, unique, index, not null | URL канала |
| `name` | `String`, nullable | Название канала |
| `folder_name` | `String`, not null | Имя папки для хранения данных канала |
| `min_date` | `Date`, nullable | Минимальная дата для обработки |
| `enabled` | `Boolean`, default `True` | Признак активности канала |
| `transliterate` | `Boolean`, default `False` | Признак транслитерации |
| `last_checked` | `DateTime`, nullable | Время последней проверки |
| `created_at` | `DateTime`, default `utcnow` | Время создания записи |

Конструктор создаётся SQLAlchemy автоматически: `Channel(**kwargs)`. Значения полей передаются по именам колонок. Ограничения `nullable=False` проверяются на уровне БД при сохранении.

### `SyncLog`

Модель журнала синхронизации. Таблица: `sync_logs`.

| Поле | Тип / параметры | Назначение |
|---|---|---|
| `id` | `Integer`, primary key, index | Первичный ключ |
| `channel_id` | `Integer`, nullable | Идентификатор канала; внешний ключ не объявлен |
| `status` | `String`, not null | Статус операции синхронизации |
| `message` | `Text`, nullable | Текст сообщения/ошибки |
| `created_at` | `DateTime`, default `utcnow` | Время создания записи |

Конструктор создаётся SQLAlchemy автоматически: `SyncLog(**kwargs)`. Поле `channel_id` логически может ссылаться на `Channel.id`, но `ForeignKey` в модели не задан, поэтому ссылочная целостность на уровне БД этим файлом не обеспечивается.

## Зависимости

- `sqlalchemy` — `Column`, `Integer`, `String`, `Boolean`, `Date`, `DateTime`, `Text` для описания колонок.
- `app.database.Base` — декларативная база SQLAlchemy; через неё модели регистрируются в metadata.
- `app.utils.utcnow` — callable-значение по умолчанию для поля `created_at`.

## Использование в проекте

В самом файле импорты других модулей проекта и вызовы моделей отсутствуют, поэтому конкретные потребители не видны. По назначению моделей предполагается, что другие модули импортируют `Channel` и `SyncLog` для ORM-операций через сессию SQLAlchemy: создание, чтение, обновление и удаление записей.

Также ожидается, что `Base.metadata` используется для создания схемы БД или миграций, а `utcnow` автоматически подставляет время создания записи при вставке, если `created_at` не задан явно.

Существующая документация в предоставленном материале отсутствовала.
