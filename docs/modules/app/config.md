# config.py

## Назначение

Модуль конфигурации приложения **DixTune**. Централизованно задаёт пути к данным, музыке, БД, логам, параметры синхронизации, аутентификации, прокси, cookies и часовой пояс. Большинство значений можно переопределить через переменные окружения. При импорте модуль создаёт каталоги данных и логов.

## Основные сущности

Функций и классов нет. Модуль предоставляет набор констант/настроек; аргументов у них нет.

- `dv_file_version` — версия файла конфигурации: `'261012.01'`.
- `BASE_DIR` — корневой каталог проекта, вычисляется от расположения `config.py`.
- `DATA_DIR` — каталог данных; env `DIXTUNE_DATA_DIR`, по умолчанию `BASE_DIR / "data"`.
- `MUSIC_DIR` — каталог музыки; env `DIXTUNE_MUSIC_DIR`, по умолчанию `/media/music/dixtune`.
- `ARCHIVE_FILE` — файл архива yt-dlp: `DATA_DIR / ".yt-dlp-archive.txt"`.
- `DB_PATH` — путь к БД: `DATA_DIR / "channels.db"`.
- `LOG_PATH` — путь к логу синхронизации: `DATA_DIR / "logs" / "sync.log"`.
- `SYNC_INTERVAL_HOURS_MIN` — минимальный интервал синхронизации в часах; env `SYNC_INTERVAL_HOURS_MIN`, по умолчанию `20`.
- `SYNC_INTERVAL_HOURS_MAX` — максимальный интервал синхронизации в часах; env `SYNC_INTERVAL_HOURS_MAX`, по умолчанию `28`.
- `DIXTUNE_USERNAME` — логин; env `DIXTUNE_USERNAME`, по умолчанию `admin`.
- `DIXTUNE_PASSWORD` — пароль; env `DIXTUNE_PASSWORD`, по умолчанию `admin123`.
- `DIXTUNE_ROOT_PATH` — корневой путь при работе за прокси с подпутём; env `DIXTUNE_ROOT_PATH`, по умолчанию пустая строка.
- `DIXTUNE_PROXY` — прокси для обхода блокировок YouTube; env `DIXTUNE_PROXY`, по умолчанию пустая строка.
- `DIXTUNE_COOKIES` — путь к файлу cookies для yt-dlp; env `DIXTUNE_COOKIES`, по умолчанию пустая строка.
- `DIXTUNE_POT_PROVIDER_URL` — URL PO Token Provider (bgutil); env `DIXTUNE_POT_PROVIDER_URL`, по умолчанию `http://bgutil-provider:4416`.
- `TIMEZONE` — часовой пояс; env `TZ`, по умолчанию `Europe/Moscow`.

## Зависимости

Используются только стандартные модули Python:

- `os` — чтение переменных окружения.
- `pathlib.Path` — работа с путями.

Зависимостей от других модулей проекта в файле нет.

## Использование другими модулями

Явные импорты и вызовы из других модулей в предоставленном файле не видны. По назначению модуль предназначен для импорта другими частями проекта, например для доступа к `DATA_DIR`, `DB_PATH`, `LOG_PATH`, `MUSIC_DIR`, параметрам синхронизации и настройкам yt-dlp.

## Особенности и ограничения

- Все настройки читаются при импорте модуля. Изменение переменных окружения после импорта не обновит уже загруженные значения.
- При импорте создаются `DATA_DIR` и каталог для `LOG_PATH`.
- `MUSIC_DIR` по умолчанию указывает на абсолютный путь `/media/music/dixtune` и автоматически не создаётся.
- Некорректные значения `SYNC_INTERVAL_HOURS_MIN` или `SYNC_INTERVAL_HOURS_MAX` приведут к ошибке `ValueError` при импорте.
- Значения логина и пароля по умолчанию (`admin` / `admin123`) подходят только для разработки и должны переопределяться в окружении для реального использования.
