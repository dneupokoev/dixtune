# utils.py

## Назначение
Вспомогательный модуль DixTune с утилитами для:
- транслитерации кириллицы в латиницу;
- очистки строк для использования в именах файлов и папок;
- создания директорий;
- получения текущего UTC-времени в виде naive `datetime`.

Версия файла: `261012.02`.

## Основные функции

### `transliterate(text: str) -> str`
Преобразует кириллические символы в латиницу по словарю `TRANSLIT_MAP`.

Аргументы:
- `text` — исходная строка.

Возвращает:
- строку с транслитерированными символами.

Особенности:
- регистр сохраняется: для заглавной кириллической буквы результат начинается с заглавной латинской буквы;
- символы, отсутствующие в `TRANSLIT_MAP`, остаются без изменений.

### `sanitize_filename(name: str) -> str`
Очищает строку от недопустимых символов для имени файла или папки.

Аргументы:
- `name` — исходное имя.

Возвращает:
- безопасное имя.

Правила:
- символы `\ / : * ? " < > |` заменяются на `_`;
- пробелы и точки в начале и конце удаляются;
- если после очистки строка пустая, возвращается `"unnamed"`.

### `ensure_directory(path: Path) -> None`
Создаёт директорию, если она ещё не существует.

Аргументы:
- `path` — путь к директории.

Использует `Path.mkdir(parents=True, exist_ok=True)`.

### `utcnow() -> datetime`
Возвращает текущее UTC-время как naive `datetime`.

Особенности:
- совместимо с Python 3.12+, где `datetime.utcnow()` считается deprecated;
- результат не содержит `tzinfo`.

## Константы и зависимости

### `TRANSLIT_MAP`
Словарь соответствия кириллических букв латинским сочетаниям. Используется функцией `transliterate`.

### `dv_file_version`
Строковая версия файла: `261012.02`.

### Импорты
- `re` — регулярные выражения для очистки имён.
- `datetime`, `timezone` из `datetime` — получение UTC-времени.
- `Path` из `pathlib` — работа с путями файловой системы.

## Использование в проекте
Изолированный анализ файла не показывает прямых импортов этого модуля другими модулями проекта. По назначению `utils.py`, вероятно, используется как общий набор утилит для:
- подготовки безопасных имён файлов и папок;
- транслитерации названий;
- создания каталогов;
- единообразного получения UTC-времени без часового пояса.

## Ограничения и заметки
- `transliterate` обрабатывает посимвольно и не выполняет контекстную лингвистическую транслитерацию.
- `sanitize_filename` не удаляет зарезервированные имена файловых систем и не ограничивает длину имени.
- `utcnow` возвращает naive `datetime`, то есть объект без информации о часовом поясе.
