# state.py

## Назначение
Модуль хранит общее состояние приложения и предназначен для предотвращения циклических импортов. Другие модули могут импортировать его как единый контейнер глобального состояния.

## Содержимое модуля
Функции и классы отсутствуют.

### Глобальные переменные
- `dv_file_version: str` — версия файла, значение `'261012.05'`.
- `current_process: Optional[subprocess.Popen]` — текущий процесс `yt-dlp`, доступный для остановки. Начальное значение `None`.
- `stop_requested: bool` — флаг запроса остановки синхронизации. Начальное значение `False`.
- `is_syncing: bool` — флаг активной синхронизации. Начальное значение `False`.

## Зависимости
Из импортов видны только стандартные библиотеки:
- `subprocess` — для типа `subprocess.Popen`.
- `typing.Optional` — для аннотации `current_process`.

Внешние зависимости отсутствуют.

## Использование в проекте
Модуль предполагается использовать как общий источник состояния: другие модули импортируют `state` и читают или изменяют переменные `current_process`, `stop_requested`, `is_syncing`. Конкретные импорты и вызовы в данном файле не видны.

## Примечание
Состояние является глобальным. Встроенной синхронизации доступа к переменным в модуле нет.
