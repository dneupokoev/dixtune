# database.py

## Назначение
Модуль отвечает за подключение приложения к базе данных SQLite через SQLAlchemy. Он создаёт движок БД, фабрику сессий, базовый класс для моделей и функцию получения сессии для использования в запросах/зависимостях.

Версия файла: `261010.01`.

## Основные объекты и функции

- `SQLALCHEMY_DATABASE_URL` — строка подключения SQLAlchemy к SQLite, формируется из `DB_PATH`.
- `engine` — SQLAlchemy `Engine`, созданный через `create_engine`.
  - Использует `connect_args={"check_same_thread": False}`, что типично для SQLite при работе с несколькими потоками, например в веб-приложениях.
- `SessionLocal` — фабрика сессий SQLAlchemy (`sessionmaker`).
  - Настроена с `autocommit=False` и `autoflush=False`.
- `Base` — базовый класс декларативных моделей SQLAlchemy (`declarative_base`).
- `get_db()` — генераторная функция без аргументов.
  - Создаёт сессию `db = SessionLocal()`.
  - Возвращает её через `yield`.
  - Гарантированно закрывает сессию в `finally`.
  - Обычно используется как зависимость для получения сессии БД на время обработки запроса.

## Зависимости
Импорты из внешних модулей:

- `sqlalchemy.create_engine` — создание движка БД.
- `sqlalchemy.orm.sessionmaker` — создание фабрики сессий.
- `sqlalchemy.orm.declarative_base` — создание базового класса моделей.
- `app.config.DB_PATH` — путь к файлу SQLite из конфигурации приложения.

## Использование в проекте
В изолированном файле нет импортов данного модуля другими модулями, поэтому фактическое использование по вызовам не видно. По экспортируемым именам ожидается, что:

- `get_db` используется как зависимость для предоставления сессии БД во время обработки запросов;
- `Base` наследуется моделями SQLAlchemy;
- `SessionLocal` используется для ручного создания сессий вне механизма зависимостей;
- `engine` используется для инициализации БД, миграций или тестов.
