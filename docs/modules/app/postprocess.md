# postprocess.py

## Назначение
Модуль выполняет постобработку одного MP3-файла после скачивания через `yt-dlp`.

Основные действия:
1. Проверяет наличие пути к файлу в аргументах командной строки.
2. Пропускает не-MP3 файлы.
3. Исправляет тег `date` (`YYYYMMDD` → `YYYY-MM`).
4. Очищает имя файла.

Модуль рассчитан на вызов как точка входа:
`python -m app.postprocess %(filepath)q`
например, через `yt-dlp --exec after_move:...`.

## Основные функции
### `main() -> None`
Главная функция модуля.

Аргументы:
- `sys.argv[1]` — путь к обрабатываемому файлу.

Поведение:
- если путь не передан — логирует ошибку и завершается с кодом `1`;
- если файл не существует — логирует ошибку и завершается с кодом `1`;
- если расширение файла не `.mp3` — завершается с кодом `0`;
- для MP3 вызывает:
  - `fix_date_tag(file_path)`;
  - `clean_one_filename(file_path)`.

Классы отсутствуют.

## Зависимости
Импорты из стандартной библиотеки:
- `sys` — чтение аргументов командной строки и завершение процесса;
- `logging` — логирование;
- `pathlib.Path` — работа с путём к файлу.

Импорты из проекта:
- `app.downloader.fix_date_tag` — исправление тега даты;
- `app.downloader.clean_one_filename` — очистка имени файла.

Обе функции вызываются с одним аргументом — `Path` к MP3-файлу.

## Использование в проекте
По видимому коду модуль используется как самостоятельная точка входа для `yt-dlp` после перемещения/скачивания файла. Явных импортов `app.postprocess` из других модулей не видно.

## Ограничения и особенности
- Обрабатываются только файлы с расширением `.mp3`; остальные типы пропускаются.
- При отсутствии аргумента или отсутствии файла процесс завершается с ненулевым кодом.
- При импорте модуля выполняется настройка `logging.basicConfig`.
- Версия файла: `261012.01`.
